## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en este proyecto, por favor repórtala de forma responsable.

- **Reporte Privado:** Utiliza la función de **Private Vulnerability Reporting** (*Private Vulnerability Reporting*) de GitHub para este repositorio.
- **Telegram:** Puedes contactarme de forma privada en [@Alrodriguezz](https://t.me/Alrodriguezz).

Por favor, evita divulgar públicamente problemas de seguridad antes de que sean subsanados. ¡Gracias por contribuir!
